# 11/5/2024 - 54th Update!

ok, quick IVO update, added scheduled section updating system! the idea first came around the time when working on [`reminder`](https://github.com/henryli-0/reminder/), and is basically a more efficient way of the system where we only update sections when needed using a form of scheduling system (or, alternatively, you can also schedule it to be updated every tick if it needs to be)! this was because the way `reminder` was made had it so that you wouldn't really need to update sections if you weren't interacting with them (except the clock and the occasional calander, but those took up less space)

the result was some ludicrous speeds (like 800 FPS)! of course, this drops significantly the second you interact with it, but that FPS at a resting speed is pretty cool! (it also makes ticks faster anyways since you only update the sections that ask for it)

one change is that if your FPS is over the `INTERFACE_FPS`, it updates all sections, since you have the time for it anyways
